# Deck search

Finds slides by title, text or speaker notes across every deck and the samples
not opened yet. The same decks and query give the same hits, scores, order and
snippets on every platform.

Source of truth: `Packages/SnazzyKit/Sources/Builder/DeckSearch.swift`.
Fixture: `search-cases.json` (decks, queries → hits, HTML → slides, snippets,
folding, `plain`). Rust: `snazzy_core::search`, `snazzy_core::fold`.

## Decks

- Every `presentation` project: from `index.html` when it has slides (title from
  `<title>`), else from `deck.json`; with the project's category (or, for an
  opened sample without one, its sector), tags and created date.
- Every sample whose `sample-<id>` project doesn't exist: category = sector,
  tags = `["Sample"]`, each slide's text = its items joined with ` · `.

## Slides from HTML

1. Remove `<script>…</script>` and `<style>…</style>` (case-insensitive, each
   replaced by a space).
2. Each `<section … class="… slide …">…</section>` (the word `slide` in the class,
   case-insensitive, lazy to the first `</section>`) is a slide.
3. Notes: the text of every `<aside class="… notes …">`, joined with a space; those
   asides are removed from the body.
4. Heading: the first `<h1>`, `<h2>` or `<blockquote>`.
5. Text: the body's plain text, with the heading taken off the front if it starts with it.

Plain text: `</li>`, `</h3>`, `</h4>` become ` · `; `<br>`, `</p>`, `</div>`,
`</hN>`, `</td>`, `</th>`, `</b>`, `</span>` a space; other tags are removed;
then `&nbsp; &lt; &gt; &quot; &#39; &apos; &mdash; &ndash; &hellip; &rarr; &middot; &amp;`
(in that order) and `&#N;`/`&#xH;` are decoded (invalid code points stay as
written); whitespace collapses to single spaces; a `·` at either end or after
another `·` is dropped.

## Folding

Case-, accent- and width-insensitive, as Foundation's
`folding(options: [.caseInsensitive, .diacriticInsensitive, .widthInsensitive])`.
Rust implements it without ICU (`fold.rs`, table generated by
`desktop/crates/snazzy-core/tools/gen_fold_table.py`):

- lower case (Unicode), plus `ß`/`ẞ` → `ss`, `ς` → `σ`, the ligatures `ﬀ ﬁ ﬂ ﬃ ﬄ ﬅ ﬆ`;
- accents: a precomposed Latin, Greek or Cyrillic letter whose canonical
  decomposition is a base letter plus marks becomes the base letter; combining
  marks are dropped. Letters without a decomposition stay (`Ø`, `Ł`, `Æ`, `Œ`
  fold to `ø`, `ł`, `æ`, `œ`, as on the Mac);
- width: fullwidth ASCII → ASCII, halfwidth katakana and symbols → their normal forms.

**Limitations**: other full case foldings, marks in other scripts, and a halfwidth
voiced-sound mark combining with the kana before it (`ﾃﾞ`) may fold differently.
Rust counts characters (Unicode scalars) where Swift counts grapheme clusters, so
snippets of text with combining sequences or emoji sequences can be cut at a
slightly different place.

## Matching and scoring

Query words = the folded query split on whitespace (none: no hits). A slide
matches when **every** word is found (substring) somewhere. Per word, first place found:

| Where | Starts a word* | Inside a word |
|---|---|---|
| heading | 12 | 8 |
| text | 6 | 4 |
| notes | 3 | 2 |
| a tag, the category, or the deck title | 1 | 1 |

\* the character before the match isn't a letter.

With more than one word, the whole phrase (words joined by one space) adds 20 in
the heading, or 10 in the text or notes.

Field shown: `heading` if a word is in the heading and no word is only in the
text/notes; else `text` if any word is in the text; else `notes` if any is in the
notes; else `heading`. Snippet source: the text for `heading` (the heading when
the text is empty), else that field. Hit heading: the slide's heading, or
`Slide <n>` (1-based) when empty. Hits are sorted by score, best first; ties keep
deck then slide order; at most `limit` (200).

## Snippets

Trimmed text of at most 140 characters is returned whole. Otherwise: find the
earliest match of any word in the folded text (when folding kept the length,
else 0), start 46 characters (140/3) before it, move back to a word start, take
140 characters, extend to a word end, trim spaces, add `…` at a cut end.
