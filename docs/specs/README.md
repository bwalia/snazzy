# Shared formats and protocols

Snazzy Pro for Mac (Swift) and Snazzy Pro for Windows and Linux (Rust, `desktop/`)
share files and talk to the same iPhone, iPad and Watch apps. They share no code,
so every format is written down here, and **the Swift code is the source of truth**:
each spec names the Swift file that defines it.

| Spec | What | Swift | Rust |
|---|---|---|---|
| [remote.md](remote.md) | Remote protocol: messages, frames, `hello` proof, pairing link | `Remote/RemoteProtocol.swift`, `RemoteSecurity.swift`, `WatchLink.swift` | `snazzy-remote` |
| [share.md](share.md) | `.snazzy` share files | `Builder/SnazzyShare.swift` | `snazzy_core::share` |
| [recordings.md](recordings.md) | `timeline.json`, `.chapters.vtt` | `CaptureEngine/Recorder.swift`, `Relayout.swift`, `Captions.swift` | `snazzy_core::timeline` |
| [decks.md](decks.md) | `deck.json`, slide layouts and their HTML, starter files, the samples | `Builder/DeckOutline.swift`, `SampleDecks.swift`, `Templates.swift` | `snazzy_core::{deck, samples}` |
| [projects.md](projects.md) | `.snazzy-project.json`, folder names, path rules | `Builder/Workspace.swift` | `snazzy_core::{project, workspace}` |
| [search.md](search.md) | Deck search: slides from HTML, folding, scoring, snippets | `Builder/DeckSearch.swift` | `snazzy_core::search` |
| [deck-repos.md](deck-repos.md) | Deck repositories on GitHub | `Builder/DeckRepo.swift`, `decks/README.md` | `snazzy_core::deck_repo` |
| [settings.md](settings.md) | App settings and presets | `SnazzyCore/AppSettings.swift`, `Presets.swift` | `snazzy_core::settings` |

## Fixtures

`fixtures/` is **generated by the Swift tests**, never edited by hand:

- `Packages/SnazzyKit/Tests/BuilderTests/SpecFixtureTests.swift` (decks, projects, share, search, deck repos, settings)
- `Packages/SnazzyKit/Tests/RemoteTests/RemoteSpecFixtureTests.swift` (remote)
- `Packages/SnazzyKit/Tests/CaptureEngineTests/TimelineFixtureTests.swift` (recordings)

```sh
SNAZZY_WRITE_FIXTURES=1 swift test --package-path Packages/SnazzyKit --filter "SpecFixture|TimelineFixture"
```

Without the variable those tests check that the committed fixtures still match
what Swift produces, and that they decode. The Rust tests (`cd desktop && cargo test`)
read the same files. A change to a format therefore fails one side until both
agree. Change the Swift code, regenerate, then fix the Rust side.

One fixture goes the other way: `share-from-rust.snazzy` is written by
`SNAZZY_WRITE_FIXTURES=1 cargo test -p snazzy-core --test share`, and the Swift
test checks the Mac opens it.

Fixtures hold made-up names and figures only, fixed dates (2026-01-02T03:04:05Z)
and fixed keys. No real keys, tokens or personal paths.

## JSON as Swift writes it

Where a spec says "byte for byte", Rust writes JSON the way Swift's `JSONEncoder`
does (`snazzy_core::json`):

- Keys sorted by UTF-8 bytes (`.sortedKeys`). Files written without `.sortedKeys`
  on the Mac (settings in UserDefaults, remote frames) have no fixed key order;
  readers must not care, and the fixtures use sorted keys.
- `.prettyPrinted`: two-space indent, `"key" : value`, and an empty array or
  object as `[`, a blank line, then the closing bracket at the parent's indent.
  No trailing newline (`deck.json` adds one).
- `/` is written `\/` unless the encoder has `.withoutEscapingSlashes`
  (only `timeline.json` and the case files do).
- Strings: `\"`, `\\`, `\b`, `\f`, `\n`, `\r`, `\t`; other characters below
  U+0020 as `\u00xx`; everything else, including non-ASCII, as is.
- Numbers: a `Double` with no fraction up to 2^53 is written as an integer (`14`,
  not `14.0`); others with the shortest round-trip digits, in exponent form
  outside 1e-4 ..< 1e16 (`1e-05`, `1e+16`).
- `Data`: standard base64 with padding. `Date`: ISO 8601 in UTC with whole seconds
  where the encoder uses `.iso8601` (every format here).
- `nil` optionals are left out (synthesized `Codable`), except where the Mac
  builds the JSON by hand (`timeline.json` writes `null`).
- Enums with associated values (synthesized `Codable`): `{"case": {"label": value}}`,
  unlabelled values as `_0`, `_1`; no values: `{"case": {}}`.
