CDN Engineer (Akamai)

Prepare for CDN and edge engineering roles: HTTP caching, edge configuration on Akamai, troubleshooting live traffic, edge security and automating changes.

Study

  • HTTP caching: Most CDN questions come back to what may be cached, for how long, and by whom.
  • Akamai delivery configuration: You'll be asked how you would set up and change properties safely.
  • Troubleshooting delivery: Interviewers want a clear method, not guesses.
  • Edge security and TLS: Most CDN roles include protecting sites at the edge.
  • Configuration as code: Safe, repeatable changes are a common interview theme.

Learn by doing (record a walkthrough of each)

  • Explain a cache key: Show that you can reason about what makes requests cacheable.
  • Debug an origin error: Practise a calm, step-by-step troubleshooting story.
  • CDN change as code: Build something you can talk about in the automation question.

Practice interview: 5 questions, with coaching afterwards.

Official resources: Akamai TechDocs · MDN: HTTP caching · MDN: HTTP response status codes · OWASP Top Ten · Terraform documentation

DevOps Engineer

Prepare for DevOps and platform roles: CI/CD, infrastructure as code, containers and Kubernetes, observability and incident response.

Study

  • CI/CD pipelines: Almost every DevOps interview asks how you ship changes safely.
  • Infrastructure as code: Expect questions on state, drift and team workflows.
  • Containers and Kubernetes: Many roles run workloads on Kubernetes.
  • Observability: You'll be asked how you'd know something is wrong.
  • Incident response: A good incident story is one of the strongest answers you can give.

Learn by doing (record a walkthrough of each)

  • Build a pipeline: Have a real pipeline to describe.
  • Break and fix a deployment: Practise an incident story end to end.
  • Infrastructure as code with review: Show safe infrastructure changes.

Practice interview: 5 questions, with coaching afterwards.

Official resources: CNCF certifications (CKA, CKAD) · GitHub Actions documentation · Google SRE book (free online) · Google SRE book: managing incidents · Kubernetes documentation · Terraform documentation

Forward Deployed Engineer

Prepare for forward deployed and solutions engineering roles: discovering customer problems, building integrations fast, working with data and APIs, and explaining trade-offs.

Study

  • Discovery with customers: The best answers show you found the real problem.
  • APIs and integrations: You'll build glue between systems.
  • Working with data: Customer data is messy.
  • Building with AI models: Many forward deployed roles now involve AI.
  • Explaining trade-offs: Interviewers test how you talk to non-engineers.

Learn by doing (record a walkthrough of each)

  • Integrate two APIs: Have a concrete build story.
  • Clean a messy dataset: Practise working with real-world data.
  • Build a small AI assistant for a 'customer': Show you can ship with AI.

Practice interview: 5 questions, with coaching afterwards.

Official resources: Anthropic courses · Anthropic documentation · MDN: HTTP overview · PostgreSQL tutorial · The Mom Test (book summary)

AI MLOps Engineer

Prepare for MLOps and AI platform roles: reproducible training and evaluation, deploying and serving models and LLM services, and monitoring quality, drift and cost.

Study

  • From experiment to production: The core MLOps story.
  • Serving models: Expect questions on latency, scale and cost.
  • Evaluating LLM applications: Increasingly asked in AI roles.
  • Monitoring models: How you'd notice a model getting worse.
  • Cloud certifications: Optional, but a structured way to learn.

Learn by doing (record a walkthrough of each)

  • Ship a model with a gate: Have a pipeline story with evaluation.
  • Evaluate an LLM feature: Show you can measure quality.
  • Monitor for drift: Practise the monitoring question.

Practice interview: 5 questions, with coaching afterwards.

Official resources: AWS certifications · Anthropic courses · Anthropic documentation: testing and evaluation · Google Cloud certifications · Kubernetes documentation · MLflow documentation
